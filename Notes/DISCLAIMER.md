# Disclaimer

The files in this folder - `nn_hardcoded.py`, `nn_notes.py`, and
`nn_variable.py`- are my own original notes and hand-coded neural network
scripts, written before I started adapting this work into the EduNet
library.

They're kept here as a historical record of how the network looked before
it became a proper class-based library (see [`EduNet/network/`](../EduNet/network))
, not as part of the installable package, and not maintained going forward.
Expect rougher code and inconsistent style, and don't assume they still run
against the current codebase.
